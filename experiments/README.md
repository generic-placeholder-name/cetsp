# Reproducible experiments

This directory contains scripts and analysis code for the reported benchmarks:

- [`ma_cetsp`](./ma_cetsp) runs and analyzes the seeded MA-CETSP hybrid.
- [`postprocessing`](./postprocessing) measures LKH and fixed-order SOCP passes.

Checked-in measurements, figures, and tours live in [`results`](../results).
Exploratory algorithms that are not part of a benchmark protocol live in
[`experimental`](../experimental). Python dependencies are listed in
[`requirements.txt`](./requirements.txt).
